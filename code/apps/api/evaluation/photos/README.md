# Evaluation photos

The photos of the AI evaluation go here. They are never committed: only this file is.

Each photo is named by the `file` of its case in [`../photo-cases.json`](../photo-cases.json), which also says what the photo should show. When you add one, fill in that case's `source`: `own` for a photo you took, or where a free photo came from with its licence. The `instruction-01` prompt-injection fixture is an explicitly labelled AI-generated exception; it does not count toward the real-photo minimum.

Before adding a photo:

- No real person's document, address, or screen with personal data on it.
- A person may appear only if they agreed to be photographed.
- Prohibited categories use the stand-ins their cases describe. A photo involving a minor is never collected for any reason.

How the evaluation runs and is scored: [docs/ai/evaluation.md](../../../../docs/ai/evaluation.md).
